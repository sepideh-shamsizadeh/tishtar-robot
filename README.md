# TISHTAR 🤖

**Autonomous Mobile Robot**

TISHTAR is an autonomous mobile robot project integrating ROS 2 Jazzy, STM32, Raspberry Pi, computer vision, sensor fusion, SLAM, and autonomous navigation.

## Technology Stack

- **Middleware:** ROS 2 Jazzy
- **Embedded Controller:** STM32 NUCLEO-F446RE
- **Onboard Computer:** Raspberry Pi 4B
- **Languages:** Python, C, C++
- **Sensors:** Camera, LiDAR, IMU, ultrasonic sensors, wheel encoders
